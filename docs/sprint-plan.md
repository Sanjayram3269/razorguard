## Non-negotiables

- Never use the test set for model selection.
- Never use future outcomes as runtime features.
- Never invent benchmark metrics.
- Every automated decision must be explainable.
- AI-generated investigation text must operate on structured evidence.
- High-impact financial actions remain policy-gated and auditable.
