# RazorGuard

**Defense-only chargeback-risk intelligence system for the Razorpay AI Buildathon — Track 02: AI Risk Manager.**

RazorGuard is being built as a production-style research prototype, not a chatbot demo.

## Design principle

> **ML detects. Graph features contextualize. AI investigates. Policy gates. Humans decide.**

The first milestone intentionally focuses on the hardest foundation: a leakage-safe synthetic transaction world and a reproducible ML evaluation pipeline.

## Current milestone

- Synthetic relational payment world
- Latent chargeback-risk generation process
- Chronological train/validation/test split
- Feature engineering with historical-only features
- Logistic Regression baseline
- Precision, recall, F1, confusion matrix
- Cost-sensitive threshold selection
- Reproducible experiment artifacts

## Important scope boundary

This repository is strictly defensive. It does not contain attack automation, evasion logic, credential abuse, or offensive fraud tooling.

## Run

```bash
python -m venv .venv
# Windows:
.venv\Scripts\activate
# macOS/Linux:
# source .venv/bin/activate

pip install -r requirements.txt

python -m razorguard.data.generate
python -m razorguard.ml.train
python -m razorguard.ml.evaluate
```

Artifacts are written to `artifacts/`.

## Evaluation contract

The test set is chronological and untouched during model/threshold selection.

We will never hard-code or invent performance numbers. The final README will only report metrics generated by the evaluation pipeline.
